# Foodly

Uma aplicação web de descoberta de pratos desenvolvida com HTML, CSS e JavaScript, criada para pesquisar pratos, explorar categorias e apresentar informações utilizando a API TheMealDB.

## Demonstração

[Clique aqui para acessar o Foodly](https://caique-torres.github.io/Foodly/)

- Pesquisa por nome do prato
- Pesquisa por categoria
- Integração com a API TheMealDB
- Exibição de pratos encontrados
- Imagens dos pratos
- Título dos pratos
- Categorias dos pratos
- Avaliação dos pratos
- Tempo de preparo
- Preço dos pratos
- Filtro por avaliação
- Filtro por preço
- Filtro por tempo de preparo
- Ordenação por popularidade
- Ordenação por avaliação
- Ordenação por nome
- Visualização dos detalhes do prato
- Modal com informações do prato
- Exibição das instruções de preparo
- Tradução das instruções para português
- Sistema de favoritos
- Categorias de carnes
- Categorias de frango
- Categorias de massas
- Categorias de frutos do mar
- Categorias de sobremesas
- Carrinho de compras
- Adição de pratos ao carrinho
- Alteração da quantidade dos produtos

## Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de HTML, CSS e JavaScript, trabalhando principalmente com criação de interfaces web, responsividade, manipulação do DOM, eventos, requisições HTTP e consumo de APIs.

O projeto também foi desenvolvido para simular uma plataforma de descoberta de pratos, permitindo pesquisar pratos, explorar categorias, aplicar filtros, visualizar informações dos pratos e adicionar produtos a um carrinho de compras.

A integração com a API TheMealDB permite obter informações dos pratos, imagens, categorias e instruções de preparo, enquanto a API de tradução é utilizada para apresentar as instruções em português.

O carrinho de compras e o processo de checkout são funcionalidades simuladas, sem realização de pedidos ou pagamentos reais.
